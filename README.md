# 사이 — 하루를 담는 작은 공간

GitHub Pages에서 사용하는 한국어 개인 다이어리. 빌드나 서버 없이 동작합니다.

- 날짜별 일기와 기분 기록, 즉시 자동 저장
- 달력 탐색, 제목·본문·날짜 검색
- JSON 백업 및 복원 (같은 날짜는 기존 기록 우선)
- 모바일 화면, 키보드 접근성, 삭제 전 확인

## 저장 방식
일기는 현재 도메인의 브라우저 localStorage에만 저장되며 GitHub에 업로드되지 않습니다. 기기·브라우저 간 자동 동기화나 비밀번호 잠금은 없습니다. 브라우저 데이터 삭제 시 기록도 지워지므로 정기적으로 JSON 백업을 내보내세요. 로컬 미리보기와 배포 사이트의 저장 공간은 서로 다릅니다.

## 실행
`python3 -m http.server 8080` 실행 후 http://localhost:8080 접속.

## 배포
GitHub 저장소 Settings → Pages → Source를 GitHub Actions로 설정합니다. main 브랜치에 push하면 포함된 워크플로로 배포됩니다. 저장소 및 사이트에는 앱 코드만 포함하세요.

폰트는 Google Fonts를 사용하며 연결되지 않으면 시스템 폰트로 표시됩니다.
